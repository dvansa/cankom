# CanKom
*Can I Commute Today?*
An Android app that checks if your daily walk/bike commute is affected by weather.

## Setup maps key

1. Create a [Google Maps API key](https://developers.google.com/maps/documentation/embed/get-api-key#create-api-keys).
2. Add line in `local.properties` passing the API key.
```
API_KEY=<google maps API key>
```
